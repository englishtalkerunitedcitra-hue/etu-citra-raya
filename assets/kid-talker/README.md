# Kid Talker source images

These six local WebP assets were extracted from the user-supplied `Landing Page ETU ( Compress ) (2).pdf`, a one-page ETU Kid Talker brochure. They are existing ETU source images, not generated or stock replacements.

- `learners.webp`: PDF image xref 93, children holding Kid Talker books.
- `guided-practice.webp`: xref 92, guided learning activity.
- `classroom.webp`: xref 98, class group photograph.
- `modules-starters.webp`: xref 87, Starters module covers.
- `modules-movers.webp`: xref 88, Movers module covers.
- `modules-flyers.webp`: xref 89, Flyers module covers.

Original image dimensions are retained. The brochure includes multiple ETU locations, so photographs are described as ETU learning documentation without claiming they all depict the Citra Raya branch. Current Citra Raya scheduling and package availability require confirmation with the branch.
